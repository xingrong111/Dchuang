# 惠山泥人 3D 资产交付 v3

资产为本项目程序化模型，不是腾讯混元生成结果。当前三成品、五部件覆盖分工方案中的基础 3D 数量要求。可在 `/model-library` 查看，`/workshop` 组装和导出。

连接链：底座.top → 身体.bottom；身体.top → 头部.bottom；身体.front → 双臂.center；双臂.front → 瑞狮.bottom。运行时按父子层级对齐局部锚点，旋转/缩放仍保持连接。删除父件也会删除附属子件并释放锚点。

源码：`src/three/modelFactory.js`、`textureFactory.js`、`assembly.js`。这是可复用建模源，不提供不存在的 Blender 文件。GLB 可导入 Blender 后进行人工雕刻和 UV 优化。

## 视觉规则

- 正面朝 +Z，Y 朝上；部件保持原始连接尺寸，成品预览统一居中。局部单位为项目建模单位，不代表实物米制尺寸。
- 以圆润盘坐/蹲坐轮廓为基础。人物头部夸张，保留惠山彩塑的笑眼、腮红、双髻、团花和祥瑞意象。
- 核心色值：朱红 #b0392e、深朱 #8f2c25、石绿 #2f7d5e、哑金 #c9a24e、肤色 #f3ddbf、米白 #ece1cc、青花 #3d6b94。
- 陶面低金属度，粗糙度基础 0.54、清漆基础 0.38。描金是局部装饰，不能全身金属化。
- 五官/袍服为嵌入的彩绘色贴图，陶土肌理为线性法线贴图。法线图采用无显式切线时与 GLTFLoader 匹配的绿通道约定。
- 纹理噪点使用固定种子，避免浏览器/导出时出现无法复核的随机视觉差异。
- 表情不被抱兽/眉须遮盖、部件不明显脱节、底座接地，是优先验收条件。

## 混元输出对照标准

混元是生成工具而非单一固定美术风格。先固定版本、输入与提示词，再比较实际输出。建议提示词为：

> 惠山彩绘泥人摆件，圆润盘坐，大头短身，朱红石绿米白哑金配色，细腻哑光陶土与局部柔和清漆，脸部传统手绘笑眼腮红，袍服牡丹团花与回纹，怀抱小型瑞狮，轮廓完整，五官清晰，无场景底板。

在资产库一样的光照、同样画面占比下比较正/侧/后/45°视角。每项 1–5 分，记录评分人及样本，不填写未经对照的分数：轮廓比例、表情文化辨识、贴图清晰度、材质、高光、组装接缝、文件体积与加载表现。人工评分不等于算法相似度。

目前未提供混元参照文件，因此只完成内部一致性与几何/纹理检查，尚未完成混元质量对照。

## 导出与验证

在 frontend 目录：

```powershell
npm run models:export
npm run models:check
npm test
```

`manifest.json` 记录 SHA-256、体积、三角形数量、包围盒与锚点。改源码后必须重新导出。GLB 保存彩绘/PBR 材质；OBJ 是无材质网格；PNG 是截图。

人工精修仍可补充衣褶、局部不对称手塑痕迹、统一 UV 图集、LOD 与手绘笔触。独立 Figma/Blender、品牌图标、状态动效与答辩 PPT 属于 D 的其余交付，不由这八个 GLB 代替。
