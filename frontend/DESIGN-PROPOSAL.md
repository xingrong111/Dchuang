# 智绘锡承 — 前端界面重构设计方案

## 一、当前问题分析

| 问题类别 | 具体表现 |
|---------|---------|
| **色彩不统一** | 每个页面独立使用颜色：首页紫色渐变、商城绿色、博物馆绿色、登录页紫色等，缺乏统一视觉语言 |
| **设计系统未落地** | `theme.css` 定义了青瓷色/赭石色/金色体系，但各页面完全没有引用，仍使用硬编码颜色 |
| **布局不一致** | 首页使用全宽布局、商城和博物馆使用侧栏布局、登录页居中布局，缺乏统一页面结构 |
| **组件风格混乱** | 按钮样式五花八门、卡片圆角不统一、边框阴影随意，无一致的组件规范 |
| **缺少文化元素** | 作为非遗平台，界面没有融入任何传统中式设计元素（如印章、水墨、云纹、窗格等） |
| **字体不统一** | 中英文混排没有明确规则，标题/正文层级不清晰 |

---

## 二、设计理念

**「青瓷水墨 · 古韵新颜」**

> 以江南青瓷色为主调，融合宣纸质感与水墨意境，辅以赭石朱砂点缀，营造「新中式非遗」的独特气质。

### 设计关键词
- **清雅** — 青瓷色为主，不张扬
- **古朴** — 圆角不宜过大，间距从容
- **精致** — 细节处见匠心，印章、墨迹等点缀
- **现代** — 布局清晰，交互流畅

## 六、组件样式规范

### 6.1 导航栏 (Navigation)
```scss
// 风格：磨砂玻璃 + 青瓷下划线
// 背景: rgba(255,255,255,0.88) + backdrop-filter: blur(20px)
// 高度: 64px
// Logo: 青瓷渐变方块 + 宋体「锡」字
// 导航项: 悬停显示青瓷背景，激活项下方显示青瓷色下划线
// 按钮: 注册按钮使用青瓷渐变胶囊
```

### 6.2 按钮 (Buttons)
```
主要按钮 (btn-primary):
  背景: 青瓷渐变 (#4a90a4 → #2d6172)
  文字: 白色
  圆角: 胶囊形 (border-radius: 9999px)
  内边距: 12px 32px
  悬停: 上移2px + 青瓷阴影

次要按钮 (btn-secondary):
  背景: 白色
  边框: 1px solid var(--color-border)
  文字: var(--color-text-primary)
  悬停: 边框变青瓷色

强调按钮 (btn-accent):
  背景: 赭石渐变
  使用场景: 价格、促销、重要操作

幽灵按钮 (btn-ghost):
  背景: 透明
  文字: var(--color-primary)
  悬停: var(--color-primary-light)
```

### 6.3 卡片 (Cards)
```
普通卡片:
  背景: 白色
  圆角: 16px
  内边距: 24px
  阴影: var(--shadow-card)
  悬停: 上移4px + var(--shadow-card-hover)

  背景: var(--color-bg-paper)
  边框: 1px solid var(--color-border-light)
  圆角: 12px
```

### 6.4 徽章 (Badges)

```

```

### 6.6 输入框 (Inputs)

## 八、中式装饰元素方案

为体现非遗特色，在界面中融入以下传统元素：

### 8.1 印章效果
用于用户身份、认证状态，例如：
```
┌─────┐
│ 锡  │  ← 红色/赭石色圆形印章
└─────┘
```

### 8.2 云纹/回纹装饰
用于页面边缘分割线、卡片装饰等，使用 SVG 实现。

### 8.3 水墨晕染效果
用于 Hero 区域背景、登录页背景等，通过 CSS 渐变 + 模糊实现。

### 8.4 竖线标题装饰
```
│ 核心功能    ← 左侧青瓷色竖条
```

### 8.5 宣纸纹理
用于次级背景区域，通过 CSS 渐变模拟宣纸质感。

## 十一、设计规范检查清单

- [ ] 所有颜色使用 CSS 变量，无硬编码色值
- [ ] 字体层级统一（标题用衬线体，正文用无衬线体）
- [ ] 间距遵循间距系统 (4/8/12/16/24/32/48)
- [ ] 圆角统一 (卡片 16px, 按钮 胶囊, 输入框 8px)
- [ ] 阴影使用设计系统变量
- [ ] 所有按钮有 hover/focus/active 状态
- [ ] 响应式在 1280/768/480 断点正常
- [ ] 图片加载失败有占位符
- [ ] 空状态有友好提示
- [ ] 加载状态有骨架屏或 loading 指示
- [ ] 导航高亮当前路由
- [ ] 表单验证有完整反馈
