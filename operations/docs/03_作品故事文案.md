## 1. 大阿福

**故事文案**
传说惠山曾有猛兽出没伤人，孩童阿福挺身而出，降兽护民。乡人感念，塑其像家家供奉。四百年来，这对盘膝而坐、怀抱瑞兽的胖娃娃，笑看了多少王朝更迭，又见证了多少无锡人家的晨昏。他从不说话，却把中国人最朴素的愿望——平安是福——笑成了一张永远的脸。

**AI 提示词**
```
中国惠山泥人大阿福，传统民间彩塑，胖娃娃头绾双髻，
盘膝而坐怀抱青狮瑞兽，笑容憨厚，脸颊桃红，
大红大绿的饱和配色配金色描边，团花云纹装饰，
陶土材质表面温润釉光，全身对称构图，居中放置，
非物质文化遗产手工艺品，影棚柔光，白底产品图
```
**标签词表**：粗货 / 大阿福 / 喜庆 / 大红 / 团花 / 瑞兽 / 盘坐

## 2. 手捏戏文·三岔口

**故事文案**
惠山艺人曾是戏园里的常客，一出戏散场，名角的水袖还在梦里翻飞，他们的指尖已经开始与泥对话。《三岔口》里两个武生在黑暗中摸手试探，明明是白昼，却让看客屏住呼吸——泥人把这一瞬的紧张捏进了眉梢，也把中国戏曲"无声不歌、无动不舞"的美学，永远留在了方寸戏台。

**AI 提示词**
```
中国惠山泥人手捏戏文，京剧武生对打场面，短打紧身衣靠旗翎子，
动态对峙定格瞬间，面部京剧脸谱开面精细，
矿物彩绘朱红石绿金黄，乌土陶胎质感，
微缩戏曲舞台场景，浅景深特写，暗色背景聚光灯效果，
国家级非遗手工艺，博物馆展品摄影
```
**标签词表**：细货 / 手捏戏文 / 京剧脸谱 / 武生 / 动态 / 朱红 / 金黄

## 3. 蚕猫

**故事文案**
江南人家养蚕，最怕老鼠偷茧。于是惠山的艺人捏出一种瞪圆了眼睛的花猫，让蚕农家家床头供一只。泥猫不吃鱼，只吃"怕"——老鼠望见那身五彩斑纹，便不敢近前。这是手艺人的幽默：用一只不会抓猫捉的老鼠的泥猫，护住了江南丝绸最柔嫩的摇篮。

**AI 提示词**
```

全身五彩条纹彩绘红黄蓝绿撞色，头部大而圆 cartoon 比例，

江南民俗生活场景道具，柔和自然光，木质桌面背景，
国家级非物质文化遗产民间玩具
```
**标签词表**：粗货 / 蚕猫 / 民俗 / 五彩 / 玩具 / 瞪目 / 蹲坐

## 4. 老寿星

**故事文案**
高高的额头，长长的银须，捧一只大过脑袋的寿桃——惠山的老寿星，是长辈们过寿时最体面的贺礼。泥塑艺人把"长寿"这个抽象的愿望，捏成了一个可以摆在堂前、可以对之敬茶的具象老人。岁月在他额头上堆出褶皱，也在手艺人的指腹间磨出温润。

**AI 提示词**
```
中国惠山泥人老寿星，民间彩塑祝寿题材，高额长须慈眉善目，
手捧巨型寿桃拄龙杖，米白长袍配朱红寿字纹，
暖金主色调辅以青绿点缀，陶土釉面质感，
端正肃立全身像居中构图，中式厅堂背景虚化，
非遗传统手工艺，产品级摄影
```
**标签词表**：粗货 / 老寿星 / 祝寿 / 寿桃 / 米白 / 朱红 / 站姿

## 5. 渔翁

**故事文案**
太湖的浪打了几千年，打湿了范蠡的蓑衣，也打湿了惠山艺人的灵感。《渔翁》捏的是水边讨生活的人：斗笠压得很低，鱼篓斜在腰间，脸上的皱纹里藏着风浪，嘴角却挂着丰收的笑。他是惠山泥人里少有的"劳动者主角"——不求福贵，只敬生活。

**AI 提示词**
```
中国惠山泥人渔翁，民间彩塑劳动者题材，头戴斗笠身披蓑衣，
腰挎鱼篓手提鲤鱼，面容饱经风霜带丰收笑容，
青灰主调配赭石橙红点缀，衣纹褶皱刻画细腻，
陶土乌胎手工捏塑质感，三分之二侧身站姿构图，
水乡氛围淡蓝背景，非遗手工艺展品摄影
```
**标签词表**：粗货 / 渔翁 / 劳动者 / 斗笠蓑衣 / 青灰 / 站姿 / 太湖

## 6. 和合二仙

**故事文案**
两位笑眯眯的仙童，一人持荷、一人捧盒，"荷"谐"和"，"盒"谐"合"。旧时无锡人办喜事，堂前必设和合二仙，让两位小小神仙替新人守着一生的口角不生、白头到老。泥巴做的神仙不灵验吗？也许吧——但五百年了，无锡的婚姻，总归是多过了一场又一场的好聚好合。

**AI 提示词**
```
中国惠山泥人和合二仙，民间彩塑喜庆题材，双童像并肩而立，
一持荷花一捧宝盒，笑容灿烂蓬头笑面，
大红粉绿撞色彩绘配金线勾边，团花纹样装饰衣缘，
陶土彩塑圆润质感，对称双人构图，
暖色喜庆氛围背景，非遗婚俗手工艺品摄影
```
**标签词表**：粗货 / 和合二仙 / 婚庆 / 荷花宝盒 / 大红粉绿 / 对称

## 7. 刘海戏金蟾

**故事文案**
"刘海戏金蟾，步步钓金钱。"少年刘海用一根彩绳逗弄三足金蟾，金钱便一枚枚从蟾口吐出。惠山艺人偏爱这个题材，因为它讨喜却不俗气——吐出的是钱，教人的却是"勤劳致福"：你看刘海笑得那么欢，那是劳作之后的笑。

**AI 提示词**
```
中国惠山泥人刘海戏金蟾，传统吉祥彩塑题材，赤足少年身披红绳，
逗弄三足金蟾，金蟾口吐铜钱造型生动活泼，
朱红金黄主色调配翠绿点缀，钱纹铜钱纹样点缀背景，
陶土彩塑光泽质感，动感对角线构图，
吉祥富贵暖色氛围，非遗民间手工艺摄影
```
**标签词表**：粗货 / 刘海戏蟾 / 吉祥 / 铜钱纹 / 朱红金黄 / 动态
