# 惠山泥人非遗介绍文案

> 用途：平台"关于我们"页、非遗数字博物馆首页导语、宣传物料通用底稿。
> 依据：中国非物质文化遗产网"泥塑（惠山泥人）"项目介绍（项目编号 Ⅶ-47，2006 年入选第一批国家级非遗名录）。

## 一、长版介绍（约 500 字，适合博物馆导语 / 报告引言）

**泥塑（惠山泥人）**，2006 年经国务院批准列入**第一批国家级非物质文化遗产代表性项目名录**（项目编号 Ⅶ-47，类别：传统美术），申报地区为江苏省无锡市，保护单位为无锡市民间艺术博物馆。

无锡地处江南水乡，惠山脚下的稻田深处，埋藏着一种细腻柔软、黏性极佳的黑土——"搓而不纹，弯而不断，干而不裂"，正是这份大自然的馈赠，孕育了延续五百余年的惠山泥人艺术。自明末起步，清代兴盛，惠山老街上曾聚集数十家泥人店、两百余家泥人作坊，形成名动江南的"泥人街"；至二十世纪初，镇上泥人店铺仍不下百家，"家家捏泥人，户户塑阿福"的盛况绵延至今。

惠山泥人分**"粗货"**与**"细货"**两大类。"粗货"以模具印制、批量彩绘而成，大阿福、蚕猫、老寿星、渔翁等喜庆吉祥题材寄托着百姓祈求祥瑞、辟邪纳福的朴素愿望，造型粗犷圆润、色彩明快奔放；"细货"即手捏泥人，艺人不用模具、徒手塑形，专攻戏曲人物、神话传说与民风民俗，人物生动传神、色调秀丽明隽，堪称"中国一绝"。

作为彩塑艺术，惠山泥人有**"三分塑，七分彩"**之说，搓、揉、挑、捏、印、拍、剪、色、压、贴、镶、划等十八般技艺环环相扣；艺人以画笔"开面"，一笔点睛，泥胎便有了呼吸。《手捏戏文》与《大阿福》名满天下，被誉为最富东方色彩的民间彩塑，与锡绣、竹刻并称"无锡三宝"。

然而今天，这项古老技艺正面临惠山泥源日益稀少、手工成本攀升、传承人才流失的严峻考验。以数字技术记录、传播、再创造惠山泥人之美，正是我们"智绘锡承"项目出发的地方。

## 二、短版介绍（约 150 字，适合首页 Banner / 海报）

一颗惠山黑土，捏过明清的风、民国的雨，也捏着今天的笑容。惠山泥人，第一批国家级非物质文化遗产，"三分塑，七分彩"，五百年来用最朴素的泥巴塑造最鲜活的人间。《大阿福》笑迎四海，《手捏戏文》演尽悲欢。智绘锡承，让千年泥韵在数字世界里继续生长——AI 共创，指尖生花。
