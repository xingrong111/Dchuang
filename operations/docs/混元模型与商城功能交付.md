## 混元实际生成

用户登录后，使用用户明确授权的现有免费额度，基于五张原创单品效果图，在腾讯混元 3D 网站生成五件模型。账户页面额度从20降为15，未充值、购买或调用付费API。下载原始文件保存于operations/deliverables/hunyuan。

网页副本将内嵌PBR贴图缩小至1024像素，保持模型几何与纹理贴图绑定，统一展示比例与底部位置。文件哈希、原始文件哈希、生成时间、来源及包围盒见frontend/public/models/products/manifest.json。拟定米制尺寸仅用于展示，不能作为已验证的制造规格。

混元模型已经整合到设计详情、资产库和3D编辑器。设计详情可旋转、缩放、重置、下载，也可点击“在工坊使用”。旧工程部件保留用于组装练习，在资产库中折叠展示。

导入命令：在frontend目录运行`node scripts/import-hunyuan.mjs 产品ID 原始GLB路径`。products:export会保留已导入的混元资产，不覆盖为程序化原型。高面数输入支持带误差限制的网格简化；当前五件均约5万面，不触发简化。优化库说明：[meshoptimizer官方文档](https://github.com/zeux/meshoptimizer/blob/master/js/README.md)。

## 商城功能

- /shop：全库搜索、分类、价格筛选、价格排序、分页、商品详情、收藏、购物车与订单提交。
- /shop/account：订单状态筛选、取消订单、运单记录、确认收货、完成订单评价、收藏管理、地址增删改和默认地址。
- /admin：商品图片、说明、价格、库存、上架状态，以及订单确认和发货；发货需物流公司和运单号。
- 评价只允许本人已完成订单中的商品，每订单商品一次；商品评分与评价数来自真实提交，不生成假评价。
- 下单价格由服务端重算，库存事务和幂等键沿用原有实现；地址属于个人私有数据，订单保存地址快照。
- 页面组件统一中文，依赖兼容升级后npm审计报告为0已知漏洞。

## 上线仍需真实资料

1. 真实货源、打样、价格与库存，以及退换/运费/交付规则。五件文创目前仍是设计展示，不能宣称已经生产或可实际发货。
2. 商家主体与支付商户配置。当前订单是待商家确认的记录，尚未接入线上支付和退款。物流记录也没有物流平台实时查询。
3. 生产域名、服务器、HTTPS和外部模型API配置。登录混元网站不等于网站已经拥有自动调用混元API的权限。
4. 工商素材原出处与使用许可、展品身份确认和文化文章原链接。
