# 共创工坊部件与多模态修复

2026-10-05 更新：本文件中的旧部件款式与来源说明已由[工坊不同造型混元部件交付](工坊不同造型混元部件交付.md)替代。多模态修复记录仍适用。

本次调整范围：六类部件库、多模态输入、工坊资源释放及网站界面文案。

## 部件清单

分类首页展示六个入口，每类进入后展示四款可旋转三维预览，支持返回分类、点击加入和拖拽加入。

| 分类 | 四款部件 |
| --- | --- |
| 头部 | 双髻朱绳、双髻青绳、金彩圆髻、桃彩圆脸 |
| 身体 | 朱红花袍、石绿花袍、杏黄花袍、月白花袍 |
| 手臂 | 环抱双臂、迎福双臂、左侧手臂、右侧手臂 |
| 底座 | 陶土圆座、青釉圆座、描金方座、圆润木座 |
| 配件 | 锦纹小书、祝福卡片、彩绘画笔、如意花饰 |
| 宠物 | 伏卧蚕猫、圆脸黄猫、青彩福猫、怀抱瑞狮 |

头部、身体、蚕猫及书本卡片基于项目已有腾讯混元模型拆分或调整，保留纹理与材质；手臂、底座、瑞狮和部分配件补充为圆润陶土、釉面风格的完整造型。24 款是拆分与配套设计成果，并非24次新的混元生成任务，本次未额外消耗混元额度。

部件可按锚点组装，配件可连接身体；支持调整、选中删除、清空、载入现有完整文创模型及GLB导出。分类切换时释放预览的三维上下文，避免反复切换后主画布变黑；离开编辑页时暂停其渲染。

## 输入修复

| 方式 | 行为与验证 |
| --- | --- |
| 文本 | 空白拦截、2000字限制、登录校验、提交期间防重复操作；已通过演示后端完成任务并预览模型 |
| 语音 | 中文识别、文本回填与编辑、停止收音、权限及网络错误提示；切换模式或离开页面停止收音 |
| 图片 | 文件选择与拖拽、格式/10MB大小/实际解码校验、预览、替换、移除；上传后可创作或分析 |
| WEBP | 补齐后端允许格式，同时校验RIFF和WEBP标记，拦截改名的其他RIFF文件 |

语音处理使用模拟识别事件验证了回填、状态和权限错误；未验证真实麦克风收音，实际语音识别取决于浏览器支持、麦克风授权与识别服务网络。

文本和图片的端到端检查使用独立验收数据库及演示服务，没有调用真实云端模型制作接口。演示返回现有混元阿福文件，界面明确说明固定预设模型；真实云端制作仍需配置对应服务接口。
